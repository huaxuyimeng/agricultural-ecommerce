工程亮点

从架构到细节的工程实践

不是「能跑就行」的 Demo，而是按生产标准构建的真实系统。

JWT + BCrypt 安全

JJWT 签发 Token，Spring Security 拦截器验证；密码 BCrypt 单向哈希，登录态自动升级。

RBAC 权限模型

USER / MERCHANT / ADMIN 三角色，路由守卫 + 菜单权限 + 接口鉴权三层防护。

可视化数据看板

ECharts 5 实时渲染销售、订单、用户、商品、库存 5 大维度数据。

商品审核工作流

WarmFlow 状态机：商家提交 → 管理员审核 → 通过 / 驳回，全程留痕可追溯。

MyBatis-Plus 高效 ORM

Lambda 表达式 + 分页插件 + 逻辑删除 + 自动填充，业务代码量减半。

Knife4j 接口文档

自动生成 OpenAPI 3 文档，所有接口在线调试，告别 Postman。

运维监控

服务器状态、性能监控、数据备份、日志审计、登录历史全链路可观测。

代码组织清晰

前后端分离 + 模块分层 + 统一响应 Result + 全局异常处理 + CORS 配置。
