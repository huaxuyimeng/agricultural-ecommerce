核心难点

开发过程中的关键挑战

01 — 架构

前后端分离架构

Vue CLI 代理跨域、Axios 统一封装请求、Vue Router 路由守卫、JWT Token 无痛刷新，前端静默保活。

02 — 核心功能

SKU 规格联动与库存校验

多规格商品属性联动、实时库存扣减校验，购物车本地缓存与持久化同步，订单状态机流转。

03 — 工程化

统一响应与全局异常处理

Result<T> 统一封装 + GlobalExceptionHandler 全局兜底，MyBatis-Plus 分页插件 + 逻辑删除中间件。
