系统架构

前后端分离，
四层治理

展示层 → 网关层 → 业务层 → 数据层：清晰的分层让每一层都能独立演进。RBAC 权限模型贯穿全栈，JWT 让前后端真正无状态。

分层设计

四个层次，职责单一

每一层都可以独立部署、独立替换，不存在跨层耦合。

L1

展示层

三端 SPA，通过 Vue Router 切换，路由守卫控制访问权限。

  • Vue 2.6
  • Vue Router
  • Element UI
  • Axios
  • ECharts
L2

网关 / 鉴权层

JWT 拦截器 + CORS + 全局异常处理，统一切面治理。

  • JWT
  • Spring Security
  • CORS
  • GlobalException
L3

业务层

Controller → Service → Mapper 三段式，事务边界清晰。

  • Controller
  • Service
  • Mapper
  • WarmFlow
  • Hutool
L4

数据层

MySQL 主存储，Redis 缓存热点，MyBatis-Plus 做 ORM 抽象。

  • MySQL 8
  • Redis
  • MyBatis-Plus
  • HikariCP
关键设计

不堆名词，看真东西

JWT 无状态认证

HS512 签名，payload 包含角色与过期时间，前端 localStorage 持久化。

RBAC 三角色

USER / MERCHANT / ADMIN，路由守卫 + 菜单权限 + 接口鉴权三层校验。

统一响应 Result

{code, message, data} 三段式，前端拦截器统一处理异常。

MyBatis-Plus

Lambda 查询、自动分页、逻辑删除、字段填充，开发效率翻倍。
